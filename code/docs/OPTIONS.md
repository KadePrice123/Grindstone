## Leg model

TYPESCRIPT (ChartDraw.ts — LANDED at lines 186-265, plus ONE additive field). ## Chain panel

A ~360px right flex column inside the page (never the main-process split-view — it must share the engine and page state), own overflow-y:auto, tabs Chain | News, toggled from VIEW; AUTO-OPENS on first preset placement or first mint (D1's invariant: the readout must be visible when zones land); auto-collapses to a drawer below ~1000px width. It is a READOUT and MINTING surface, not the primary instrument — the chart stays the centerpiece per Kade's verbatim hierarchy. HEADER: symbol + the endpoint's source string VERBATIM ('alpaca (indicative)' | 'none', later 'your recorded data · age') agreeing with provider_status.options_chains — one honesty vocabulary; manual refresh button. LEGS STRIP: one row per leg in slot order — hue swatch, SELL PUT 612.4 (driven values styled '← TL-2'), expiration (DTE) ± tolerances, match count; every field typeable; one strategy summary row per complete group: 'Condor forms @ 9/18 · net 2.15 cr (mid) · widths 6/6', and the honest partial state raw counts hide: 'legs match, no common expiration'. Net credit computed at mid ONLY when every leg has a real bid — otherwise 'net — (no bid on 2 legs)' (closes D2's own contradiction). PER-LEG SECTIONS: matched contracts from the landed endpoint, already sorted nearest-strike-first with sooner-expiration tie-break (options.py:64-67); rows show strike/right/expiration, bid×ask + relative spread %, delta when present and an explicit 'Δ —' when the indicative feed omits it (never 0, never interpolated), 'no bid' instead of a fabricated mid, zero-bid excluded from 'nearest' ranking. truncated:true renders as 'showing 400 of N — narrow the window', never silently. NO OI/volume column, NO POP/theoretical/P&L — the feed can't honor them and filtering-only is the scope. IDLE STATE (no legs yet, D2's steal): an expiration accordion with DTE badges built from fetched dates (real listed dates — Good-Friday Thursdays and SPY dailies come from data, never a Fridays rule) plus 'place a leg or pick a strategy to filter'; expanding a section issues one windowed fetch (that date, wide strikes) — the accordion is the lazy loader and also feeds date-snapping. Clicking bid/ask in any row MINTS a leg (creation door 3); clicking a row while a leg is selected POPULATES that leg (detaching a hosted leg with notice) — filtering only, nothing routed. EMPTY/NO-CREDS STATE — the FIRST state every e2e run and fresh install sees: a findable .chain-empty node rendering the endpoint's reason verbatim ('no data key — add an Alpaca account to see live chains', the landed wording), cross-linking Data management's one-click setup-recording; never a spinner-forever, never fake rows; zones still render with '—' counts because leg geometry needs no market data. REFRESH POLICY (D3's contract): fetches fire on panel open, symbol change, endDrag commit, typed-edit commit, and preset apply — one in-flight request, coalescing latest windows, one request per leg window (the landed endpoint takes one window; group legs' windows are usually distinct anyway); drags NEVER fetch; a passive re-poll at most every 60s while open behind a per-symbol monotonic cooldown (the live_news_allowed pattern). The server's per-tuple 45s TTL absorbs repeat commits; with upstream params landed, each fetch is 1-2 pages, not 13 — but the counting-fake gate mutation still proves the cache prevents refetch amplification. STATE PLUMBING: leg state reaches the panel THROUGH the page's single assigned engine.onChange (a second subscription silently disconnects DrawEditor and the data-draw-* attrs — comment this at the assignment site); panel open/closed lives in a ref outside updaters (the indStash StrictMode rule). Closing the panel is render-only — zones persist, the 30s summary poll continues (Metrics depends on it). v1.1: thinkorswim-style COMBO VIEW when a preset is armed — one row per candidate whole-spread per strike/width, click commits the group with those strikes.

## Presets

Placement primitive is % of spot refined by expected move — NEVER delta (indicative-feed greeks are legitimately absent for 0DTE/zero-bid; the e2e scratch profile has no creds; instantiation must be deterministic from bar data alone). spot = last loaded daily close; EM = spot · iv_atm · sqrt(DTE/365) when the last fetched slice carries ATM IV; fixed-% fallback otherwise (the path the gate tests): Δ.50≈ATM, Δ.30≈±3% (0.5·EM), Δ.16≈±5% (1·EM), Δ.05≈±8-10%. Delta is chip decoration only. Expiration seeds to the listed date nearest the target DTE when dates are known (accordion/last fetch), else the raw calendar date weekday-adjusted. Strikes snap to the chain grid FOR DISPLAY only (grid step = mode of adjacent strike diffs near ATM; SPY = $1); the stored anchor stays continuous — the tolerance band does the matching ('612.4 (nearest listed 612)'). V1 CATALOGUE (side right @ placement; one shared expiration per group via the group tag; default 45 DTE; slots assigned 0..3 in listed order; picker tagged by outlook — bullish/bearish/neutral/volatility, Robinhood taxonomy, tags on the PICKER only): Long call: +C @ ATM. Long put: +P @ ATM. Covered call: −C @ +3% (0.5·EM), chip notes 'stock leg implied'. Cash-secured put: −P @ −3%. Call debit vertical: +C @ ATM, −C @ +3%. Put debit vertical: +P @ ATM, −P @ −3%. Put credit vertical: −P @ −3%, +P @ short − max(1%, 5 grid steps). Call credit vertical: −C @ +3%, +C @ short + max(1%, 5 steps). Iron condor (Kade named it; the flagship four-color test): −P @ −5% (1·EM), +P @ 1% further down; −C @ +5%, +C @ 1% further up. Iron butterfly: −P and −C @ ATM (same strike — the landed slot-stepped chip interleave keeps both clickable), +P @ −5%, +C @ +5%. Straddle: +C and +P @ ATM (short = one flip-both-sides toggle on the group). Strangle: +C @ +5%, +P @ −5%, same toggle. DEFAULT TOLERANCES (per-leg, all typeable): dteTol from CHAIN DENSITY, never a symbol list — >3 expirations in the next 10 days (daily-expiry underlyings) ±2cd; weekly cadence ±3cd ('exactly this week's expiration'); monthly-only ±7cd; no chain data → ±3cd. strikeTol: ATM/short legs max(1 grid step, 0.5% of spot); wings max(2 steps, 1% of spot); caps respected (validator: dteTol ≤ 60, strikeTol ≤ 500). Note MAX_LEGS = 12 (landed) bounds concurrent structures: an iron condor + a vertical + spares fit; the picker refuses a preset that would exceed it with a worded message. V1.1 FAST-FOLLOWS: Calendar (−@ ATM 30d front, + same strike 60d back — per-leg expirations already work since expiration lives on each leg; only the shared-band rendering needs a pass), Diagonal/PMCC (+C @ −1·EM ITM 90-180d, −C @ +0.5·EM 30d), Channel vertical (short leg bound to one trend, long to a parallel trend via the shipped shared-slope value — the showcase of lines-as-filters), symmetric condor wing drag (Shift mirrors the opposite side). Later, zero engine work: broken-wing fly, jade lizard, ratios, collar. APPLYING UX: STRATEGY toolbar group (picker + 'Leg' + 'Clear legs'); ONE click instantiates at defaults, selects the group, auto-opens the panel — then everything is the drag/type grammar. Placement is a PURE function (spot, bars, lastSlice?) → OptionLeg[], exported and fixture-tested for both the EM and fallback paths.
